## Developer / Linux Groups Post

Built something fun for Linux devs who use Claude Code.

Pip is an open-source pixel-art desktop companion — she chats via the Claude Code CLI, so no separate API key is needed. Right-click for games, Pomodoro timer, and settings. Left-click to chat. Double-click to pet her.

Features:
- Full Claude AI chat (web search included)
- Music awareness — dances when tracks change
- Relationship system — her personality evolves over time
- Pomodoro, daily challenges, wellness reminders
- Mini-games from the right-click menu

Python + PyQt6. Polyform Noncommercial license (free for personal use).

GitHub: github.com/gourab026/claude_companion
