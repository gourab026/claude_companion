## General Announcement (Claude AI / AI Tools servers)

```
Hey everyone! I built something fun and wanted to share it here.

Meet Pip — a tiny pixel-art AI companion who lives on your Linux desktop.

She chats via Claude Code CLI (no API key needed), dances to your music,
plays games with you, and grows a real personality the longer you hang
around. Four relationship levels from "polite stranger" to "best friend
who writes diary entries about you".

What she can do:
  Full AI chat via Claude Code (web search included)
  Dances when new music starts + fetches artist facts
  Mini-games: Trivia Quiz, 20 Questions, Rock Paper Scissors
  Built-in Pomodoro timer (shouts at you at 25 min)
  Daily word of the day + coding challenge
  Remembers notes you tell her to save

100% free for personal use. Open source.

GitHub: github.com/gourab026/claude_companion

Would love to know what you all think!
```

## r/ClaudeAI Discord / Claude-related servers

```
built a fun thing with Claude Code CLI

instead of using the Anthropic API, Pip runs `claude -p "prompt"` in
a background thread — so she gets web search + your MCP servers for
free, and you don't need a separate API key

the personality system dynamically injects your relationship level,
shared topics, vocabulary you've taught her, and mood history into
the system prompt on every call — her replies actually reflect your
history together

open source, linux only for now

github.com/gourab026/claude_companion
```
