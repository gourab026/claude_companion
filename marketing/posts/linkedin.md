## Post Copy

I spent the last few months building something I've always wanted: a tiny AI companion that actually lives on my desktop.

Meet **Pip** — a pixel-art character powered by Claude Code. She chats, dances to your music, plays games with you, and slowly develops a real personality over time.

What makes her different:

**No API key required.** Pip talks to Claude through the Claude Code CLI — if you're already using it, she just works.

**She genuinely grows with you.** Four relationship milestones track your history together:
→ New Friend (0–24 chats) — polite and careful
→ Acquaintance (25–99) — warmer, starts making jokes
→ Friend (100–499) — playful, sends you haikus and challenges
→ Best Friend (500+) — teases you, writes diary entries about your day

**Built for focused developers:**
→ Pomodoro timer with an animated shout bubble at 25 min
→ Music awareness via MPRIS — dances when tracks change
→ Daily word, coding challenge, and time-aware greetings
→ "Remember: X" to save notes instantly
→ Mini-games from the right-click menu (Trivia, 20Q, RPS)

Built with Python + PyQt6. Open source under the Polyform Noncommercial license — free for personal use.

If you're a developer on Linux who uses Claude Code, I'd genuinely love for you to try it and tell me what you think.
