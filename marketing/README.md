# Pip Marketing Kit

## Assets

All assets are SVG — open in a browser or Inkscape, export to PNG at the recommended resolution.

| File | Dimensions | Use |
|---|---|---|
| `assets/avatar.svg` | 512×512 | Profile picture on all platforms |
| `assets/banner_hero.svg` | 1200×630 | Universal OG/social card, Facebook, general |
| `assets/banner_linkedin.svg` | 1200×627 | LinkedIn post image / profile banner |
| `assets/banner_discord.svg` | 1280×640 | Discord announcement, general dev servers |
| `assets/banner_reddit.svg` | 1200×400 | Reddit post header |

### Exporting to PNG (browser method)

1. Open the SVG in Chrome or Firefox
2. Right-click > "Save image as..." — or —
3. Use Inkscape: `inkscape banner_hero.svg --export-png=banner_hero.png --export-width=1200`

## Posting order (recommended)

1. **Reddit** first — organic discovery, drives GitHub stars
2. **Discord** same day — immediate feedback loop from dev community
3. **dev.to / HN** next day — drives sustained traffic
4. **LinkedIn** 2–3 days later — professional reach
5. **Facebook** last — broadest audience, lowest conversion but high visibility
