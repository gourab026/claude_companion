Get Pip running

Installation

Works on any x86_64 Linux with a compositor. Python 3.9+ required.

Install the Python dependencies, make sure Claude Code CLI is authenticated, and run. That's it — Pip appears in the corner of your screen.

A compositor (picom, KWin, Mutter…) is required for transparency. On bare X11 the window will be opaque.

  • PyQt6 ≥ 6.4.0 — window and rendering
  • pynput — typing-idle detection
  • psutil (optional) — CPU/RAM commentator
  • xdotool — active window watcher
  • playerctl — music detection via MPRIS
bash 
# 1. Install Python dependencies
pip install PyQt6 pynput
pip install psutil   # optional — CPU/RAM reactions

# 2. Install optional system tools
sudo apt install xdotool playerctl

# 3. Ensure Claude Code CLI is installed & authenticated
claude --version   # should print a version number
claude -p "hi"    # should return a response

# 4. Run Pip
cd /path/to/companion
python main.py
